可见性规则

规则保存在 config.yaml 的 plugins.configs.cpa-model-visibility 段，保存后立即热生效（无需重启）。 模型条目可以直接点选，也支持通配符：abc* 前缀、*abc 后缀、a*bc 两端锚定、* 全部；deny 永远优先于 allow。 「提供方」是模型条目的 owned_by 字段（厂商名，不是渠道名）：codex 渠道的模型 owned_by 显示为 openai，候选列表里已标注渠道对应关系。
