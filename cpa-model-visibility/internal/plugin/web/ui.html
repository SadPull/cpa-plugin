可见性规则

规则保存在 config.yaml 的 plugins.configs.cpa-model-visibility 段，保存后立即热生效（无需重启）。 模式支持精确、abc* 前缀、*abc 后缀、a*bc 两端锚定、* 全部；deny 永远优先于 allow。
